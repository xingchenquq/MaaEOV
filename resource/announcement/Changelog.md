- 适配：**新版游戏主界面**
  - 主界面改版后，作战 / 招募 / 事务所 / 补给站 四张功能卡的整卡模板全部失效（旧模板匹配度 0），

  - 底部功能条、左上活动入口、任务入口的位置都变了，对应模板一并重切。
  - 活动 banner 从「右侧中部」移到「左上」，`当期活动` 用来判断活动是否开放的 ROI 同步更新，
    否则会误判成「本期无活动」直接跳过。
  - 实测 13 个依赖主界面的任务全部通过。

- 修复：**事务所（解读仪式）**
  - **假成功**：旧版把「追加」按钮的模板当作「解读完成」判据，残片耗尽时会命中追加弹窗里的同款「追加」按钮 → 弹窗没关就判任务完成（实测 12.5 秒报 OK，构想之钥与残片都没变动）。现改为识别页面中央的「暂无档案残片」。
  - **只认第一个探员**：原来固定点第一张卡的「开始仪式」，遇到该探员休息就整单结束。现在按卡位顺序逐个判断，休息中的跳过，换下一个可用探员。
  - **追加弹窗兜底**：构想之钥不够时弹窗点不动，会反复重开直到超时。现在点完「追加」若弹窗仍在，自动点「取消」退出并正常收尾。
  - **分解护符只分解一次**：确认分解后原本直接结束，仓库里有别的护符也不会继续。现在回到仓库重新判断，直到清零。
  - **修正选项「解读仪式偏好」**：探员页右侧那条资源筛选栏其实是可点的，旧坐标点在图标间隙上，导致选哪个偏好都等于没选。坐标下移到图标中心（y 240/330/415/500）后，筛选会真正切到对应资源，再从筛选结果里挑第一个可用的探员。

- 修复：**补给站**紫心奖章售罄后死循环
  - 商品「剩余购买次数0」的收尾节点缺 `next`，关掉弹窗后又回到上层重新点开同一商品，实测卡满 540 秒。现在点确定后直接收尾；货币不足提示同样补了关闭动作。
  - **「胶卷兑换」（用多余探员碎片换银心奖章）明确不做支持**：该入口从未接入流程，本次已清理全部相关文案与选项。

- 修复：**危机行动调令**扫荡完成后任务被判失败
  - 扫荡是「一次把调令打完」，结算后已经在主界面，但流程末尾还挂着「重试选关」——主界面找不到关卡，一路回落到导航，实测 94.6 秒后 FAIL（调令已消耗、收益却没结算）。现在扫荡结束直接收尾。

- 修复：**往期活动**多数选项选了必失败 / 永远不扫荡
  - 7 个活动里 6 个引用的模板文件根本不存在（实际文件名带关卡后缀，如「谜案回首GB112.png」），只有「在月光之下」能用。现改为 OCR 识别活动名，7 个选项全部可用。
  - 读取「往日行动调令」的 OCR 没写过滤正则，拿到的是 ROI 里任意一段文字（实测读到「福」），解析成 0 → 明明有 6 个调令却走了「调令为零」跳过，**从未真正扫荡过**。已补 `[0-9]` 过滤。

- 修复：**清体力**体力耗尽后停在「使用体力道具」弹窗
  - 现在会先关掉弹窗再结束，不留界面残留。

- 修复：**当期活动**活动结束后任务必红
  - 原实现靠主界面活动 banner 的「剩余X天」定位，活动一结束就 30 秒超时判失败，与说明里写的「自动跳过」不符。现在主界面无 banner 时直接跳过并记为完成。


## v1.17.0

- 新功能：**认知海域**（双周本）正式可用
  - 完整流程打通：BCR「终局行动」→ 认知海域进入 → 关公告与奖励一览 → 选层 → 下潜方式 → 配队 → 全局灵感 → 战斗节点循环 → 满额后**自动返回游戏主界面**。
  - 意识碎片满 `1000/1000`、或入场券不足 2 张时自动收尾并退回主界面，不会白耗券。
  - 若存在未完成的下潜，先「终止下潜」放弃当次探索再重新开始（不做续跑，避免局内状态错乱）。
  - 单次约 8~19 分钟，满额需 2 轮。任务超时建议给 1200 秒以上。
- 新功能：**认知海域-Buff配置** 选项
  - **配置一（默认·原样）**：不读卡名，全局灵感选最左一张、局内灵感选左卡，行为与旧版一致，推荐使用。
  - 配置二（低配稳健·实验）：OCR 读出卡名后按优先级打分，优先护盾 / 减伤 / 回复类。权重表在 `resource/base/data/soc/buff_priority.json`，改数据即生效、无需改代码。该配置仍在验证中，个别界面布局下可能少拿几张灵感（不会卡死任务）。
- 修复：认知海域此前**从未真正跑通过**，本次实机排查累计修复 15 处缺陷，主要几条：
  - **入口路径整体错误**：认知海域在 BCR「终局行动」的二级菜单里，不在底部功能条。原实现用「认知海域图标」模板找入口，位置根本不对，永远匹配不到。
  - **全局选卡动作未注册**：`custom_action` 误写在 `action` 顶层而非 `action.param` 内，整段选卡逻辑从未被调用。
  - **截图取错对象**：`SoCAwaitBattle` / 全局选卡 / 存失败截图 三个动作拿到的是作业句柄而非图像，全部静默失效且不打错误日志。
  - **灵感标签只取单个框**：识别结果用的是「最佳框」，整屏多张可选卡只认得出 1 张，导致反复选同一张。
  - **战斗等待不认「已退回选层」**：打完本轮最后一个节点后游戏直接回选层，没有「继续」按钮，原逻辑死等 540 秒并判为失败。
  - **「未选择灵感」弹窗点击落空**：弹窗关不掉常驻遮挡界面，之后 OCR 只能看到边缘一张卡，选卡必然失败。
- 更新方式
  - 本版**改动了 `agent/`**。资源包（`*-resource-win-x64.zip`）已含完整 `agent/`，可在程序内「检查更新」直接升级，**无需重下完整包**。
  - 若要更新程序本体（exe / dll / 运行库），才需要完整包。

## v1.16.0

- 新功能：领取任务可单独关闭
  - **一键领取**拆成三个可独立开关的领取项：`日常任务奖励` / `周常任务奖励` / `应对协议奖励`（关闭协议奖励时整段跳过，含交付步骤）。
  - **活动领取**同样拆成三项：`邮件` / `每日行动补给`（午间+晚间两档共用一个开关）/ `短期支援补贴`。
  - 默认全部开启；全部关闭时任务立即结束。关掉某一项不影响后面几项继续执行。
- 修复
  - **阈限禁区选错关卡**：三个关卡的「已到达」判据此前完全相同（都用详情页通用的「扫荡/进入探索」按钮），互相冒充 —— 选「回廊 42区」时若角色停在上次那关的详情页，会直接扫那一关，白吃每周 480 上限。现改用详情页左上角标题区的关卡名判定，三关互斥。
  - **阈限禁区卡在选关卡**：`_NavigateReceptionRoom` 原来用 `inverse` + 全屏 OCR 关卡名当判据，而关卡名在选择页卡片上就存在 → 判据恒成立 → 2ms 失败并空转 30 秒。现改为纯调度节点。
  - **阈限禁区跳过选关**：`LiminalZoneFromLevel` 用「扫荡」按钮判「已在关卡详情页」，且排在选关卡之前——只要停在上次那关的详情页就直接开扫，选关逻辑永不执行。现改为先确认到达目标关卡再扫荡。
  - **在别的关卡详情页时点不到卡片**：新增「退回关卡选择页」节点，自动点左上角返回后重新选卡。
  - **危机行动收尾卡在个人信息页**：`退出关卡详情页` 的模板误判后无路可走，空转 30 秒判失败（调令已消耗、收益拿不到）。新增个人信息页兜底 —— 原判据写的是「UID/签到/公告」，但该页实际写的是「ID: xxx」、也没有那两个词，等于从未生效；现已改用该页独有文案。
  - **BCR 兜底导航误判**：`_NavigateBCR` 的判断用「主线故事」这个底部页签，而 BCR 所有子页底部都有同一排页签 → 从子页触发兜底时误判「已在 BCR」而不导航。现改用首页顶部按钮区。
- 更新方式
  - 本版**未改动 `agent/`**。资源包（`*-resource-win-x64.zip`）已含完整 `agent/`，可在程序内「检查更新」直接升级；
    若需更新程序本体（exe / dll / 运行库），请用完整包。

## v1.14.2

- Bug修复
  - 修复 v1.14.1「退出应用」任务仍不生效的问题。根因是 `taskkill /F /T /PID` 命令作为 agent 子进程被拉起，而 `/T` 会先清理目标进程树内的所有后代，导致 taskkill 自身也被连带杀死、命令来不及执行。改为通过 **`wmic process create "taskkill ..."`** 启动结束命令：wmic 创建的 taskkill 父进程为 `wmiprvse.exe` / `services.exe`，**不在 MaaEOV 进程树内**，不会被 `/T` 顺带清理，能够完整执行并结束宿主树。保留按名结束的次路径与直接 taskkill 兜底。

## v1.14.1

- Bug修复
  - 修复「退出应用」任务结束后不生效的问题：原实现依赖按名字 / 按父进程名猜测结束宿主，当运行时 exe 名不匹配或父进程名解析不出时两条路都没动手，程序纹丝不动。改为**按当前 agent 进程的父进程 PID（`taskkill /F /T /PID`）强制结束宿主进程树**为主路径（与 exe 名、是否改名、是否经启动器拉起均无关），按名结束仅作父 PID 解析失败的备份；移除了先优雅等待 2 秒再强制的方案
