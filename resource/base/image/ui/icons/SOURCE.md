# 任务图标：源与配色规范

## 权威版本在哪

**本目录下的 PNG 是唯一权威版本。**

早先的设计源在 Ardot 画布（`ardot.tencent.com/file/746348972236756`），但画布上仍是
「每个任务一种颜色」的旧方案，与这里的统一配色不一致。
**不要从画布重新导出覆盖本目录**，否则会打回彩色版本。

## 当前配色

| 部位 | 色值 | 说明 |
|---|---|---|
| 底 | `#E3E8EF` | 浅灰蓝，和白色卡片有区分但不抢眼 |
| 符号 | `#3D4A5C` | 深蓝灰，与底对比约 7:1 |

选这个方案的原因：界面是浅色主题（`config/config.json` 的 `BaseTheme: Light`）。

- 试过「每个任务一种颜色」→ 16 色相像调色盘，且任务按使用频率排序、与分类顺序不一致，
  同类颜色被拆散到列表各处，交错跳跃。
- 试过「深底 + 白符号」→ 在浅色列表里像一排黑痣，压过任务文字。
- 最终：**统一浅底 + 深符号，靠图标形状区分任务**。

## 规格

- 96×96 PNG，RGBA，圆角外完全透明（alpha=0）
- 设计尺寸 48×48，2 倍导出
- 圆角矩形 `x=2 y=2 w=44 h=44 rx=13`
- 符号居中，线宽 2.3~2.6，`linecap/linejoin = round`

## 新增任务时

1. 在画布上按上述规格画符号（底色画什么都行，下一步会被统一覆盖）
2. 导出 96×96 PNG 放进本目录
3. 跑 `python scripts/apply_icon_color.py` 统一刷成当前配色（幂等，已刷过的会跳过）
4. 在 `interface.json` 对应 task 里加 `"icon": "image/ui/icons/<文件名>.png"`

## 换主题注意

切到 Dark 主题时，这套浅底图标会反过来跳（浅色方块浮在深背景上）。
MFA 的图标是静态 PNG，没有主题感知能力，浅色/深色只能二选一。
真要支持深色主题，需要另存一套并用 `pipeline_override` 或构建期切换。
