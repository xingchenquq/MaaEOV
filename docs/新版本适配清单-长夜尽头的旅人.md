## 2. 更新后第一次跑之前的检查（重要）

### 2.1 先手动启动一次游戏

`_LaunchGame` timeout 仅 30s，`_NavigateHomepage` → `_EnsureHomepage` 的等待窗口也是 30s。**大版本首次启动要下载资源包，很可能超过 30s** → 「启动游戏」直接失败。

做法：更新完成后先手动开游戏，等它把资源下完、进到主界面，再跑任务。

### 2.2 留意新公告弹窗

新版本首次登录会有版本公告弹窗，`_CloseWindowsGeneral`（模板 `Utils/CloseWindows.png`）若匹配不上新样式，会卡在主页判定。出现时补一张新模板或改用 OCR「关闭/X」。

### 2.3 逐项截图顺序（省来回切界面）

1. 主界面右上角 banner（含「剩余X天」）→ 定 `进入活动页` 的 roi
2. 活动主页 → 「危险地带」入口 → 裁 `当期活动/危险地带.png`
3. 关卡地图 → 关卡代号（绿幕末位字形法）→ 替换 `选择危险地带关卡` 模板
4. 危机行动界面 → 关卡列表第 1 页 + 最后一页（确认是否有新关卡、S 编号规则）
5. 联线封锁界面 → 奖章数与结算文案
6. 应对协议 → 四周常 tab + 是否「已满级」
